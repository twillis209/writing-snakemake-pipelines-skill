# Review against Snakemake v9.27.0 (2026-10-07)

Audited every reference/asset claim against `git show v9.27.0:<path>` in the
snakemake repo, and ran the assets + review fixture under a v9.27.0 venv.
Note: snakemake `main` is v9.27.0 + unreleased `feat!` 91763d64 (`software:`
directive, plugin-based deployment) — likely v10; not treated as shipped.

## A. Broken (fails at runtime / non-existent API)

1. `assets/workflow/schemas/*.yaml`, `configuration.md:56,83` — `$schema: https://json-schema.org/draft-06/schema#` → `UnknownDialect`; every snakemake command on the scaffold fails. Use `https://json-schema.org/draft/2020-12/schema` (validate() uses Draft202012Validator since 9.6). Inherited from upstream configuration.rst.
2. `samples.schema.yaml` `paired: boolean` vs `common.smk` `dtype=str` → ValidationError. Drop `paired` (fq2 presence already decides).
3. `example.smk:22` `{input.r2:q}` → AttributeError for single-end; also no `--r2` flag. Use a named params function returning `--r2 <path>` or `""`.
4. `--set-default-resources` (SKILL.md:28, rule-anatomy.md:65) doesn't exist → `--default-resources`. Typo inherited from best_practices.rst.
5. semantic-helpers.md:169-177 `subpath(input[0], …)` in `output:` errors (outputs can't be functions); also reviewing.md:32, fixture F10 fix. Use in params, or `multiext`.
6. semantic-helpers.md:190 `{as_py_module(...)}` in shell string → NameError. Move to `params:`.
7. semantic-helpers.md:148-155 `default_resources:` shown as Snakefile directive — it's profile YAML.
8. configuration.md:116,118 YTE example uses undefined `env()` / `os`; also puts threads in config (contradicts the file).
9. `assets/.github/workflows/main.yml:14`, testing-and-ci.md — `snakemake/snakefmt@v0.8.5` is not an action (no action.yml). Use `super-linter/super-linter@v8` with `VALIDATE_SNAKEMAKE_SNAKEFMT`, or `pip install snakefmt && snakefmt --check`. Bump `actions/checkout`.
10. Lambda lint doesn't exist (testing-and-ci.md:9, verification-checklist.md:28, v7-to-v8:89-91). Lambda avoidance is best_practices guidance, not a lint.
11. verification-checklist.md:25 suggested `log: "logs/{rule}/{wildcards.sample}.log"` itself errors. :46 WildcardError explanation is reversed.
12. `--use-conda`/`--use-singularity` described as removed (deployment.md:13, v7-to-v8:20) — still accepted, silently mapped.
13. v7-to-v8:85-87 "Defaults shift" section wrong on all three items.
14. testing-and-ci.md:49-51 unit-test generation recipe generates nothing; needs `--notemp` run then `snakemake --directory .tests/integration --generate-unit-tests "$PWD/.tests/unit"` (from code reading, not run).
15. `profile.yaml` only recognised from 9.19 — scaffold has `min_version("9.0")`, so on 9.0–9.18 the profile silently isn't loaded.
16. Global `container:` doesn't apply to module-imported rules (scoped since 9.25.2) — deployment.md:63.
17. modularization.md:117 `gh:…@tag` "cacheable" — code passes ref as branch → re-fetched every run (upstream docs claim otherwise).

## B. Stale vs 9.23→9.27

- Positional `lookup("query-or-dpath", within=…)` (9.25) — docs now use it everywhere.
- `branch(cases=…, otherwise=…)` (9.24); without otherwise, no-match raises KeyError.
- `--generate-unit-tests` shows diffs (9.27); `common.py` is regenerated, so customise per-test.
- Dry-run with `--executor` validates against that executor (9.27).
- `continuumio/miniconda3` → `condaforge/miniforge3` (deployment.md:69).
- Wrapper tag example `v3.4.0` → current `v9.x`.
- Global `wildcard_constraints` after rules dropped temp/protected/touch before 9.25.2.
- v8-to-v9: typed-snakemake break is 9.17.0 (not 9.17.3), new import form; missing `--log-handler-script` removal.
- snakefmt 2.0.3 reorders directives → assets fail `snakefmt --check`.

## C. Imprecise / overstated

- "Pulled directly from best_practices.rst" — several non-negotiables come from other docs or are the skill's own.
- `default_target` "required for module composition" — backwards/overstated.
- Pathvars presented as *the* way to make roots configurable; upstream calls config-set pathvars "rare, discouraged"; output folders → `--directory`.
- `docker://` "works under Docker and Apptainer" — snakemake only runs apptainer.
- `--profile workflow/profiles/default` double-loads; it's auto-applied.
- choose_* param names/None returns; parse_input timing; log rationale; reviewing.md "remote://" v7 claim, "see above" dangling, mermaid vs report.
- Absolute-path lint has false positives on concat fragments (fixture shows 6) — reviewers shouldn't escalate them.

## D. Omissions worth adding (selective)

Reports (`report()`), resource unit strings (`mem="8GB"`), named logs (stdout/stderr), threads → OMP/MKL env vars, `configfile:` relative to workdir (unlike everything else), PEP needs peppy+eido, v7→v8 removals (`dynamic()`, `version`, `subworkflow`), `--keep-incomplete` keeps shadow dirs.

## Verified OK (highlights)

All helper names/versions (choose_* 9.22, as_py_module 9.20, pathvars 9.12, gh:/gl: 9.23), all other CLI flags, `profile.yaml` loads on 9.27, `run:`+conda claim, review fixture's 12 findings still hold.

## Status

Fixes applied on branch `v9.27-fixes` (commit 6a015b0 + follow-up). Decisions:
keyword `lookup` forms kept (positional documented as 9.25+); `software:`
directive left out until released; scaffold floor `min_version("9.19")`.
